# 豆包 Seedream AI 图像生成工作台（BYOK 专业版）

为火山引擎豆包 Seedream 大模型（如 `doubao-seedream-5-0-260128`）打造的高效、专业、清爽的图像创作工作台。采用用户自主密钥（BYOK）模式，默认采用清新自然的中文浅色界面设计，兼顾单图精细化参数调优与高产出的批量自动化处理。

---

## 用户确认与核心设计决策

> [!IMPORTANT]
> 根据确认，工作台的核心架构与技术选型如下：

- **数据持久化**：全面采用**浏览器原生 IndexedDB** 作为核心存储引擎。完整保存生成图片的大图数据（Blob / Base64）、请求参数快照、Prompt、Seed、时间戳与标签，突破 localStorage 5MB 限制，确保持久保存海量作品与极速检索。
- **API 接入架构**：采用**纯前端浏览器直连模式**（BYOK，用户输入并安全本地存储 `ARK_API_KEY`），同时内置自定义 API 端点/反向代理地址配置项与 CORS 诊断指引，确保网络灵活适配。
- **批量与自动化重点**：深度支持**提示词多行队列批量生成**与**变量模板占位符批量笛卡尔积展开**（如 `{主体}`、`{光影}`、`{风格}` 多维度替换），并提供一键导出 Python 与 cURL 自动化执行脚本功能。
- **历史记录与资产管理**：基于 IndexedDB 的本地相册管理器，支持列表筛选、大图灯箱预览、参数一键回填再创作、多选批量操作以及**一键打包 ZIP 归档下载**。
- **界面与交互风格**：严格遵循**中文浅色界面**、UI 简洁克制、无无效装饰（Anti-AI Slop），注重工作区空间利用率与信息层级。

### 1.1 核心参数控制中心（精细单图创作）
- **模型与端点**：预置 `doubao-seedream-5-0-260128`、`doubao-seedream-4-0`，并支持自定义模型接入点 ID（如 `ep-2025...`）。
- **画质与分辨率（Size）**：快捷切换 `2K`、`1K`、`1024x1024`、`1280x720`、`720x1280`、`2048x1024`，并支持主流画幅比例（1:1, 16:9, 9:16, 4:3, 3:4, 21:9）。
- **生成高级控制**：
  - 连续生图（`sequential_image_generation`: `disabled` / `enabled`）
  - 响应格式（`response_format`: `url` / `b64_json`）
  - 水印开关（`watermark`: `true` / `false`）
  - 流式开关（`stream`: `false`）
  - 负向提示词（Negative Prompt）过滤不良元素
- **多维度风格预设库**：
  - 预设分组：电影大片/科幻、真实人像摄影、国风水墨古韵、日漫/插画、3D/OC 渲染光追、赛博朋克、极简艺术等。
  - 点击快捷将高质量画质修饰词（如“景深、OC渲染、体积光、真实质感”）插入至当前光标或追加末尾。

### 1.2 批量自动化生成中心（生产力核心）
- **提示词列表队列**：每行一条提示词，支持一键批量载入、粘贴、文本文件导入，自动生成任务队列。
- **变量模板批量替换（Matrix Expander）**：
  - 支持在提示词中书写占位符，例如：`星际穿越，{主体}，{视角}，{光影}`
  - 为每个变量定义替换词组列表，实时预览笛卡尔积组合数（如 3 种主体 × 2 种光影 = 6 个生成任务）。
- **执行控制器**：支持启动、暂停、取消、单项重试；实时显示生成进度、耗时与状态指示。
- **自动化脚本导出器（Script Exporter）**：
  - 实时将当前参数、提示词或队列转换为可直接运行的 **Python 脚本**（含 requests、并发重试）及 **Shell cURL 命令**，方便在服务器终端或自动化流程中使用。

### 1.3 IndexedDB 历史画廊与导出中心
- **IndexedDB 存储设计**：
  - Database: `DoubaoSeedreamStudioDB`
  - Object Store: `generated_images`（主键 `id`，索引：`createdAt`, `model`, `favorite`）
  - 字段：`id`, `prompt`, `negativePrompt`, `model`, `size`, `parameters`, `imageUrl`, `imageBlob`, `createdAt`, `durationMs`。
- **大图灯箱预览**：支持高清查看、原比例缩放、提示词与请求参数一键复制、一键回填到编辑器重新生成。
- **批量导出**：多选后一键使用 JSZip 打包下载为 `.zip`，文件命名规范有序（包含时间戳与提示词缩写），亦支持单张快捷保存。

## 2. 界面视觉与交互规范（浅色极简）

- **整体风格**：纯净、克制、浅色专业工程质感（遵循 Anti-AI Slop 准则，杜绝炫目光晕与无意义的渐变大胶囊）。
- **色彩策略（60-30-10）**：
  - 60% 基础画布：浅灰白背景（`bg-slate-50` / `bg-neutral-50`）
  - 30% 功能面板：纯白卡片（`bg-white`），带有精细的 `border-slate-200` 单层边框和柔和微阴影。
  - 10% 重点交互：火山引擎经典商务蓝/青蓝（`#1664FF` 或 `indigo-600` / `blue-600`）作为主操作和进度按钮，强调高对比度与清晰指示。
- **排版布局**：
  - 顶部导航栏（Top Bar Contract）：左侧产品标识，中间模块切换（单图创作 / 批量自动化 / 历史画廊 / 脚本导出），右侧 BYOK 密钥配置与端点设置入口。
  - 创作区：双栏黄金比例工作台，左栏为参数、风格与提示词编辑，右栏为即时生成视口与快速历史流。

## 4. 实施里程碑

1. **依赖与基础库准备**：安装 `jszip`，实现 IndexedDB 本地持久化管理器与火山引擎 API 客户端。
2. **BYOK 与全局状态管理**：实现 API Key 本地安全隔离存储，支持端点自定义、连接测试与配置校验。
3. **单图创作中心与参数面板**：构建提示词编辑器、负向词输入、风格预设选择器、模型与尺寸参数网格。
4. **批量处理与变量模板模块**：编写多行提示词解析器、大括号占位符模板展开引擎与队列调度器。
5. **自动化脚本生成器**：实现将当前工作台配置实时生成 Python 与 cURL 脚本。
6. **IndexedDB 历史画廊与 ZIP 打包**：完成本地作品列表渲染、图片灯箱预览、多选与批量 ZIP 打包下载。
7. **编译验证与全流程测试**：运行 `compile_applet` 确保构建无错误，验证交互流畅性与错误处理完备性。
